# 历年案例主题

案例分析是 5 题选 3，每题约 25 分。长期稳定的题型是：质量属性或架构风格（常作必答）、UML 或设计模式、数据库或缓存、嵌入式、Web 或安全。下面只记考点，不抄题干。

2009–2018 年的完整案例在 [真题](../真题/README.md)，下面只记考点。2019 年本地 PDF 是扫描件，主题没有抽出。2020 年起的主题按公开回忆版核对。

## 2009 下半年

1. 在线交易平台：六种质量属性，四条需求对应的质量属性与架构策略
2. 商业情报：流程图与数据流图的区别，数据流图错误
3. 宇航嵌入式：LRM、三层栈、故障分类与容错
4. 定速巡航：过程控制风格，构件与控制步骤
5. B2C 扩展到互联网：安全威胁、认证、抗抵赖

## 2010 下半年

3. 汽车电子：嵌入式架构与实时性
4. TeleDev：开发工具集成、企业应用集成
5. 数据流软件：可靠性模型与评估

## 2020 下半年

1. 必答：在线开发系统，管道-过滤器与仓库风格对比，质量效用树
2. 包裹信息管理：逻辑模型、关系模式与主键、超类实体、派生属性
3. 嵌入式：FACE 五段（操作系统、I/O、平台服务、传输、可移植组件），需求到架构的映射
4. Redis 数据类型与功能对应，过期删除失效后的内存淘汰
5. 工业检测 Web：性能、安全性、可用性分类，SSM 流程填空

## 2021 下半年

1. 必答：机器学习平台效用树；解释器、管道-过滤器、隐式调用在流程灵活性与算法扩展上的对比
2. 预约挂号：用例图、顺序图，对象模型、动态模型、功能模型
3. 嵌入式：FACE 与数据架构
4. 数据库反规范化，Redis 同步
5. 智能家居：家庭网关与云平台在网关管理、数据处理、性能上的差别，架构图填空

## 2022 下半年

1. 必答：在线交易效用树；面向对象风格与解释器风格在规则可修改性、灵活性、性能上的对比
2. 煤矿安全预警：数据流图平衡、ER 图、数据字典
3. 嵌入式：四层架构，心跳与超时探测，核/分区/模块/系统监控，数据驱动诊断
4. 仓储：缓存同步与异步、一致性哈希分片、布隆过滤器
5. 工业物联网：MQTT，端-边-云，边缘计算相对纯云计算的通信、安全与性能

## 2023 下半年

1. 必答：Lambda 与 Kappa，批处理层、速度层、服务层，架构图填技术组件
2. Web：JWT 认证与 Web 安全
3. Redis 数据丢失、读写分离
4. Hibernate ORM 架构
5. SysML 需求图

## 2024 上半年

1. 必答：微服务优缺点，质量效用树，质量属性场景六元素
2. UML 序列图：同步消息、异步消息、返回消息
3. 分布式锁：数据库锁的缺陷，Redis 锁，死锁，ZooKeeper / etcd
4. 嵌入式（公开回忆不完整）
5. Web 分层与数据库选型（MySQL、HDFS、HBase、Elasticsearch），MongoDB，冷温热数据

## 2024 下半年

1. 质量属性场景填空；可用性故障检测：ping/echo 与心跳
2. Cache-Aside 读写流程，多线程下缓存与数据库不一致
3. 嵌入式：ROS 与 ROS 2，四种通信
4. Web：Elasticsearch 四种分词器，架构图填空，RESTful 与前后端分离
5. 胰岛素泵：危险驱动的安全分析，形式化开发与测试

## 2025 上半年

1. 在线大模型训练平台：质量属性场景；解释器风格组成，以及为什么适合该平台
2. Redis 主从复制的全量复制与增量复制，RDB 与 AOF
3. 医药知识图谱分层，Scrapy 与异步 I/O，图数据库存储
4. 嵌入式：云侧 AI 与端侧 AI
5. 区块链

## 2025 下半年

这一场机考有多个批次，公开回忆分成两套，选题时两套都要会。

批次一：

1. 嵌入式实时系统：定义与特性，强实时 / 弱实时，错误、缺陷、故障、失效
2. FACE 宇航开放式软件架构
3. Scrum 与 MVC、SSH
4. Redis 数据类型、RDB/AOF、缓存淘汰
5. 无人直升机：状态图与活动图

批次二：

1. 质量属性场景六要素，AES-256 与性能的权衡
2. 领域驱动设计：限界上下文、离线同步
3. Redis 缓存击穿：互斥锁与逻辑过期
4. 后两题公开回忆不完整

## 2026 上半年（回忆版，部分小问缺失）

1. 智慧养老：物联网分层，边缘侧时序数据库，MQTT 的 QoS 0/1/2
2. 自适应学习：用户冷启动，知识图谱构建与稀疏性
3. 秒杀：悲观锁与乐观锁，Redis 高并发控制
4. 智能安防 AIoT 四层：感知、边缘、AI 决策、应用
5. 实时入侵检测：质量属性识别；批处理序列与管道/过滤器的选用
