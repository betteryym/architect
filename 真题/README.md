# 系统架构设计师真题

2020 年下半年到 2026 年上半年来自 `awesome-ruankao/真题/系统架构设计师`，是考生回忆版。2024 年下半年论文原文里有空字符，整理时已去掉。

2009–2018 年下半年来自 `system_architect` 里的答案详解，三科都带参考答案。图和表还在 PDF 里。2019 年那份是扫描件，抽不出文字。2020 年以后两边都有，笔记里保留原来的回忆版，没有用 PDF 覆盖。`system_architect` 里 2022、2025 上半年也是扫描件，2024 上半年目录里没有题目正文。

每场目录里三份文件：`综合知识.md`、`案例分析.md`、`论文.md`。2025 年上半年另有一份综合知识回忆版 PDF。各场试题标题统一成二级标题，方便大纲跳转。

## 论文题目

2009–2018 的四题全文在各年的 `论文.md`，题名汇总在 [历年真题/论文题目](../历年真题/论文题目.md)。

| 场次 | 四选一 |
|---|---|
| 2020 下 | 企业集成架构；软件测试缺陷管理；云原生架构；数据分片 |
| 2021 下 | 面向方面编程；系统安全架构；企业集成平台；微服务架构 |
| 2022 下 | 基于构件的开发；软件维护；区块链；湖仓一体 |
| 2023 下 | 面向对象建模；软件可靠性评价；多源数据集成；边缘计算 |
| 2024 上 | Lambda 架构；模型驱动架构；单元测试；云上自动化运维 |
| 2024 下 | 软件维护；面向服务架构；多源异构数据集成；分布式事务 |
| 2025 上 | 事件驱动架构；软件测试方法；负载均衡；多模型数据库 |
| 2025 下 | Serverless；云原生数据库；性能测试；秒杀 |
| 2026 上 | 向量数据库；高并发；六边形架构；多模态大模型测试 |

## 案例主题

2009–2018 的考点在 [历年真题/案例主题](../历年真题/案例主题.md)，全文在各年的 `案例分析.md`。

| 场次 | 五题 |
|---|---|
| 2020 下 | 架构评估（管道/过滤器与仓库）；包裹数据库设计；FACE；Redis 类型与淘汰；SSM 工业检测 |
| 2021 下 | 架构风格与效用树；预约挂号 UML；FACE 与数据架构；反规范化与 Redis；云平台智能家居 |
| 2022 下 | 效用树与解释器风格；数据流图与 ER；宇航故障检测；缓存分片与布隆过滤器；MQTT 与边缘计算 |
| 2023 下 | Lambda 与 Kappa；JWT 与 Web 安全；Redis 丢失与读写分离；Hibernate；SysML 需求图 |
| 2024 上 | 微服务与效用树；UML 序列图；分布式锁；嵌入式；MongoDB 与冷热数据 |
| 2024 下 | 质量属性与心跳；Cache-Aside；嵌入式；Web 与分词；软件开发 |
| 2025 上 | 大模型训练平台与解释器；知识图谱；Redis 主从与持久化；云 AI 与端 AI；区块链 |
| 2025 下 | 两套批次。其一：实时系统、FACE、Scrum 与 MVC、Redis、状态图。其二：质量属性与 AES、DDD、缓存击穿 |
| 2026 上 | 智慧养老与 MQTT；自适应学习；秒杀锁；AIoT 四层；入侵检测与管道/过滤器 |
